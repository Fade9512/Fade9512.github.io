KMP：复用已经获得的信息

为什么不必从头再来

当一个模式串已经匹配了一部分，失配前获得的信息并没有消失。KMP 使用前缀函数保存这些信息。

设 πi\pi_iπi​ 表示以位置 iii 结尾的子串中，最长相等真前缀与后缀的长度。

前缀函数

#include <string>
#include <vector>

std::vector<int> prefix_function(const std::string& s) {
    int n = static_cast<int>(s.size());
    std::vector<int> pi(n);
    for (int i = 1; i < n; ++i) {
        int j = pi[i - 1];
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) ++j;
        pi[i] = j;
    }
    return pi;
}

复杂度

指针每次增加至多一步，回退的总次数也受此前增加次数约束，因此计算前缀函数的时间复杂度是 O(n)O(n)O(n)。

总增加次数+总回退次数=O(n).\text{总增加次数}+\text{总回退次数}=O(n).总增加次数+总回退次数=O(n).

想通的关键不是记住循环，而是理解：每次回退都在寻找仍有可能成立的较短候选。
